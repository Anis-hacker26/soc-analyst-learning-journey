# 🛡️ SOC Analyst Learning Journey

Welcome to my **SOC Analyst Learning Journey**.

This repository documents my hands-on journey toward becoming a Security Operations Center (SOC) Analyst through practical labs, investigations, and documentation.

Rather than simply completing courses, this repository focuses on learning by doing—building a home lab, investigating Windows events, analyzing Sysmon logs, practicing threat hunting, and documenting every step.
